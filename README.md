# LLM-friendly база знаний по ГОСТ серии 77

## Назначение репозитория

Этот репозиторий предназначен для хранения и структурирования текстов стандартов ГОСТ серии 77 в формате, оптимизированном для обработки большими языковыми моделями (LLM).

### Цели проекта

- Предоставить машиночитаемую базу знаний по стандартам ГОСТ серии 77
- Обеспечить удобный доступ к текстам стандартов для LLM
- Поддерживать актуальную информацию о статусе и взаимосвязях стандартов
- Упростить поиск и навигацию по документации

## Структура репозитория

```
gost-kb/
├── README.md              # Этот файл
├── llms.txt               # Конфигурация для LLM-агентов
├── INDEX.md               # Полный индекс всех стандартов
├── GLOSSARY.md            # Глоссарий терминов
├── scripts/               # Скрипты для обработки и конвертации
├── source-docx/           # Исходные документы в формате DOCX
└── standards/ # Стандарты в Markdown
    ├── _template/ # Шаблоны для новых стандартов
    │   ├── full.md        # Шаблон полной версии
    │   ├── summary.md     # Шаблон краткого описания
    │   └── metadata.json  # Шаблон метаданных
    ├── lci/ # Стандарты жизненного цикла (LCI)
    │   └── 77-XXX/
    ├── eskd/ # Стандарты ЕСКД
    │   └── XXXX/
    └── interop/ # Стандарты интероперабельности
        └── XXXXX/
```

## Форматы файлов

### Markdown (.md)
Основной формат для текстов стандартов. Обеспечивает:
- Читаемость человеком
- Легкость парсинга для LLM
- Поддержку структуры через заголовки

### JSON (.json)
Формат для метаданных. Содержит:
- Номер и название стандарта
- Статус и даты
- Связи с другими стандартами
- Ключевые слова для поиска

### DOCX (.docx)
Исходные файлы для верификации и конвертации.

## Использование

### Для LLM-агентов

Файл `llms.txt` содержит инструкции для AI-ассистентов о структуре репозитория и способах навигации.

### Поиск стандартов

1. Используйте `INDEX.md` для поиска по номерам и названиям
2. Обратитесь к `GLOSSARY.md` для поиска по терминам
3. Изучите `standards/{domain}/{standard-id}/metadata.json` для детальной информации

## Вклад в проект

При добавлении нового стандарта:
1. Создайте папку `standards/{domain}/{номер стандарта}/`
2. Скопируйте шаблоны из `standards/_template/`
3. Заполните `metadata.json`, `summary.md`, `full.md`
4. Добавьте исходный DOCX в `source-docx/`
5. Обновите `INDEX.md`
