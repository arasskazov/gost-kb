# ГОСТ Р 55062-2021: Краткое изложение

## Назначение стандарта

ГОСТ Р 55062-2021 «Информационные технологии. Интероперабельность. Основные положения» определяет единый подход к обеспечению интероперабельности информационных систем широкого класса. Стандарт устанавливает основные понятия, эталонную модель интероперабельности и методику достижения интероперабельности через последовательность основных и вспомогательных этапов.

**Дата введения:** 2022-04-30  
**Взамен:** ГОСТ Р 55062-2012

---

## Область применения

Стандарт предназначен для:
- заказчиков информационных систем
- поставщиков программно-аппаратных решений
- разработчиков ИС
- потребителей ИТ-услуг
- персонала, сопровождающего информационные системы

Стандарт охватывает системы различного масштаба — от наносистем до систем класса «системы систем».

---

## Основные термины и определения

| Термин | Определение |
|--------|-------------|
| **Интероперабельность** | Способность двух или более ИС/компонентов к обмену информацией и использованию полученной информации |
| **Интероперабельная система** | Система, в которой подсистемы работают по независимым алгоритмам без единой точки управления; управление определяется профилем интероперабельности |
| **Интегрированная система** | Система с единым алгоритмом работы всех подсистем и единой точкой управления |
| **Профиль интероперабельности** | Согласованный набор стандартов, структурированный в терминах модели интероперабельности |
| **Эталонная модель интероперабельности** | Развитие семиуровневой модели ВОС с тремя уровнями: технический, семантический, организационный |
| **Барьер интероперабельности** | Несовместимость сущностей, препятствующая обмену информацией или использованию сервисов |
| **Семантическая интероперабельность** | Способность систем одинаковым образом понимать смысл обмениваемой информации |
| **Техническая интероперабельность** | Способность к обмену данными между системами |
| **Организационная интероперабельность** | Способность систем достигать общих целей на уровне бизнес-процессов |
| **COTS-продукт** | Коммерчески доступный программно-аппаратный модуль со стандартными интерфейсами |

**Сокращения:**
- ИКТ — информационно-коммуникационные технологии
- ИС — информационная система
- ВОС — взаимосвязь открытых систем

## Ключевые требования по разделам

### Эталонная модель интероперабельности

Модель включает три уровня:

1. **Технический уровень**
   - Описывает синтаксис и форматы передаваемой информации
   - Ключевые аспекты: открытые интерфейсы, службы связи, интеграция данных, middleware
   - Достигается через стандартные протоколы (TCP/IP)

2. **Семантический уровень**
   - Описывает содержательную сторону обмениваемой информации
   - Позволяет системам обрабатывать смысловое содержание данных
   - Достигается через стандарты XML, XSD, RDF, OWL

3. **Организационный уровень**
   - Акцентирует прагматические аспекты (деловые, политические)
   - Согласование бизнес-целей и соглашений о сотрудничестве
   - Достигается через нормативно-правовые документы

> Интероперабельность значима только при взаимодействии на всех трёх уровнях.

### Методика обеспечения интероперабельности

**Основные этапы:**
1. Разработка концепции интероперабельности
2. Построение архитектуры системы
3. Построение проблемно-ориентированной модели
4. Построение профиля интероперабельности
5. Программно-аппаратная реализация
6. Аттестационное тестирование

**Вспомогательные этапы:**
7. Разработка дорожной карты стандартов
8. Разработка национальных стандартов
9. Разработка глоссария

### Требования к концепции

Концепция должна содержать:
- определение интероперабельности
- описание всех этапов обеспечения
- оценку экономического эффекта
- барьеры и подходы к их преодолению
- возможности количественной оценки

### Требования к архитектуре

- Использование сервис-ориентированного подхода
- Распределенные, слабо связанные (loose coupling) компоненты
- Стандартизированные интерфейсы и протоколы
- Учет тенденции к сетецентрической архитектуре

### Программно-аппаратная реализация

- Построение из COTS-продуктов со стандартными интерфейсами
- Независимость от конкретного поставщика
- ~4-кратная выгода по сравнению с монолитными системами

## Экономический эффект

Основной источник экономии при создании интероперабельных систем — отсутствие необходимости разрабатывать дополнительные интерфейсы (переходные модули, шлюзы).

Использование COTS-продуктов обеспечивает примерно 4-кратную выгоду по сравнению с построением монолитных систем.
