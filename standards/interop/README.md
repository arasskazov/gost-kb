# Домен INTEROP — Интероперабельность промышленных систем

## Назначение домена

Домен `interop/` содержит базу знаний стандартов по **интероперабельности
промышленных систем и цифровых платформ**.

Интероперабельность (interoperability) — способность разнородных систем,
устройств и приложений обмениваться данными, корректно интерпретировать их
и совместно использовать в рамках единого технологического процесса.

**Основной орган стандартизации:** Росстандарт  
**Статус стандартов:** национальные (ГОСТ Р)  
**Область применения:** промышленная автоматизация, IoT, цифровые двойники,
киберфизические системы, интеграция гетерогенных платформ.

---

## Связь с доменом LCI

Домен `interop/` тесно связан с доменом `lci/` (Life Cycle Integration):

| Стандарт LCI | Связь с интероперабельностью |
|--------------|------------------------------|
| ГОСТ Р 77.402 | Интеграция данных жизненного цикла |
| ГОСТ Р 77.403 | Форматы обмена данными между системами |
| ГОСТ Р 77.404 | Протоколы взаимодействия компонентов |

Стандарты `interop/` расширяют требования LCI, добавляя:
- Семантическую совместимость онтологий
- Протоколы реального времени (OPC UA, MQTT, AMQP)
- Требования к безопасности межсистемного взаимодействия
- Модели цифровых двойников и их синхронизации

## Ожидаемая структура поддиректорий

По аналогии с доменом `lci/`, каждый стандарт размещается в отдельной
директории с именем вида `{номер-стандарта}/`:

```
standards/interop/
├── README.md              ← этот файл
├── 55062-2021/            ← ГОСТ Р 55062-2021
│   ├── full.md            ← полная нормализованная версия
│   ├── summary.md         ← краткое изложение (1–2 стр.)
│   ├── metadata.json      ← метаданные и глоссарий
│   └── media/             ← изображения, схемы, диаграммы
└── ...                    ← другие стандарты интероперабельности
```

## Добавление нового стандарта

1. Создать директорию `standards/interop/{номер}/media/`
2. Извлечь текст из исходного DOCX/PDF в `full.raw.md`
3. Нормализовать в `full.md` (Markdown-заголовки, таблицы, ссылки)
4. Создать `summary.md` (1–2 страницы)
5. Создать `metadata.json` по образцу `standards/lci/77-001/metadata.json`
6. Запустить `python build_index.py` для обновления индексов
7. Закоммитить изменения
