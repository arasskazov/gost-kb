# ГОСТ Р 2.525-2024 — Краткое содержание

## Назначение стандарта

Стандарт устанавливает формат данных электронной конструктивной структуры изделия (ЭСК) в рамках Единой системы конструкторской документации (ЕСКД).

## Область применения

Стандарт применяется при создании, хранении и обмене электронными конструктивными структурами изделий на всех стадиях жизненного цикла продукции.

## Основные термины

Термины приняты по ГОСТ Р 2.005, а также:
- **контекст** — идентифицированная (именованная) точка зрения, созданная в рамках информационной модели и уточняющая особенности решаемой задачи

### Сокращения
- ЕСКД — Единая система конструкторской документации
- СЧ — составная часть
- ЭСК — электронная конструктивная структура изделия
- JSON — JavaScript Object Notation
- XML — extensible Markup Language

## Ключевые требования

### Общие положения
- ЭСК является электронным конструкторским документом, определяющим состав сборочной единицы, комплекса или комплекта
- Модель данных ЭСК описывает изделие и его составные части согласно ГОСТ Р 2.101

### Состав модели данных ЭСК
Модель данных позволяет описывать:
- изделия и составные части, включая материалы
- исполнения изделий
- основную ЭСК изделия
- допустимые замены и подборные СЧ
- материалы для изготовления деталей
- роли организаций (разработчик, изготовитель, держатель подлинников)
- конструкторские документы

### Форматы передачи данных
При передаче содержательную часть ЭСК представляют в форматах:
- STEP-JSON (приложение Б)
- STEP (ГОСТ Р ИСО 10303-21)
- XML или другом стандартизованном формате

Выбор формата определяется по соглашению между сторонами.
