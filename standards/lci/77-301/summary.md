# ГОСТ Р 77.301 — краткое содержание

## Область применения

- Настоящий стандарт устанавливает основные положения по разработке схем данных, используемых для создания стандартизованных информационных моделей изделий машиностроения, применяемых для:
- \- представления конструкторской, технологической и прочей документации в машиночитаемом виде;
- \- долговременного хранения документации в нейтральном формате данных;
- \- обмена данным между разными программными средствами.

## Ключевые положения

- 4.4 Стандарты ГОСТ Р 77.3ХХ (группа 3) описывают составные части общей схемы данных об изделии, на основе которой может быть создана ИМ изделия, содержащая сведения об изделии в необходимом объеме, с учетом п.4.3.
- 4.5 Для решения конкретных прикладных задач на основе схем данных, указанных таблице 1, могут по правилам, установленным в ГОСТ Р ИСО 10303, разрабатываться прикладные протоколы.
- 4.6 Правила описания схем данных для стандартов ГОСТ Р 77.3XX (группа 3), а также схем данных для прикладных протоколов, приведены в разделе 5.
- 5.1 Состав информационных объектов, связей, атрибутов и правил, используемых при представления (описания) схем данных, в целом определяется стандартами ГОСТ Р ИСО 10303.
