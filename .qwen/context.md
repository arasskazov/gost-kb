# База знаний: ГОСТ Р серия 77 — Система поддержки жизненного цикла изделия

## Что это за репозиторий

Репозиторий `arasskazov/gost-kb` содержит **13 стандартов серии ГОСТ Р 77.*** в формате,
оптимизированном для работы с LLM (нормализованный Markdown, метаданные, глоссарий).

Тематика: **Система поддержки жизненного цикла изделия (СПЖЦ)** —
стандарты ТК 482, охватывающие информационную модель изделия, программные средства
и интероперабельность.

---

## Структура репозитория

```
gost-kb/
├── INDEX.md              ← индекс всех 13 стандартов (таблица с путями и описаниями)
├── GLOSSARY.md           ← агрегированный глоссарий 40+ терминов из всех стандартов
├── llms.txt              ← машиночитаемая навигация для LLM
├── standards/
│   ├── 77-001/
│   │   ├── full.md       ← КАНОНИЧЕСКИЙ ТЕКСТ (нормализованный Markdown)
│   │   ├── summary.md    ← краткое содержание на русском
│   │   ├── metadata.json ← метаданные, ключевые слова, связанные стандарты
│   │   └── media/        ← извлечённые изображения
│   └── ... (аналогично для 77-002 … 77-404)
├── source-docx/          ← исходные DOCX-файлы
├── reports/              ← QA-отчёты о качестве конвертации
├── normalize_standard.py ← скрипт нормализации DOCX → Markdown
└── build_index.py        ← скрипт сборки INDEX.md, GLOSSARY.md, llms.txt
```

## Правила работы с базой

### Приоритет источников
1. `standards/77-XXX/full.md` — **главный источник**, нормализованный текст стандарта
2. `standards/77-XXX/summary.md` — для быстрой ориентации, не для цитирования
3. `GLOSSARY.md` — для поиска определений терминов
4. `INDEX.md` — для навигации по корпусу
5. `standards/77-XXX/metadata.json` — для поиска связанных стандартов и ключевых слов

### Обязательные правила ответов
- Отвечай ТОЛЬКО на основе содержимого `full.md` из этого репозитория
- **Всегда указывай:** номер ГОСТ + номер раздела/пункта (например: ГОСТ Р 77.001, п. 4.3)
- Если информации нет ни в одном из `full.md` — прямо скажи об этом, не придумывай нормы
- Цитируй текст стандарта дословно, без парафраза
- При противоречиях между стандартами — укажи оба варианта с источниками

### Навигация по вопросу
- **Вопрос о конкретном стандарте** → читай `standards/77-XXX/full.md`
- **Поиск определения термина** → сначала `GLOSSARY.md`, затем `standards/77-002/full.md`
- **Нужны связанные стандарты** → смотри поле `related_standards` в `metadata.json`
- **Обзор всей серии** → читай `INDEX.md`, затем нужные `summary.md`
- **Вопрос об ИМ изделия** → стандарты 77.301–77.306
- **Вопрос о программных средствах** → стандарты 77.402–77.404
- **Базовые положения и термины** → стандарты 77.001, 77.002

## Типичные задачи и как их решать

### Ответить на вопрос по конкретному стандарту
```
Прочитай standards/77-XXX/full.md и ответь: [вопрос]
```

### Найти определение термина
```
Найди определение термина "[термин]" в GLOSSARY.md и standards/77-002/full.md
```

### Сравнить положения нескольких стандартов
```
Прочитай standards/77-001/full.md и standards/77-101/full.md
Сравни, как в каждом из них определяется [понятие]
```

### Проверить документ на соответствие стандартам
```
Прочитай standards/77-XXX/full.md (нужный стандарт)
Проверь следующий фрагмент документа на соответствие требованиям: [фрагмент]
Укажи конкретные пункты стандарта, которые нарушены или выполнены.
```

### Составить глоссарий для документа
```
Прочитай GLOSSARY.md и standards/77-002/full.md
Составь глоссарий для документа, используя только термины, определённые в этих файлах.
```

## Важные замечания

- **Язык:** все стандарты на русском языке
- **Статус:** большинство документов — проекты стандартов (status: "project"), не утверждённые ГОСТ
- **Источник:** тексты получены из официальных DOCX-файлов через автоматическую конвертацию с нормализацией
- **Таблицы:** в ряде стандартов (77.305, 77.306) сложные таблицы были преобразованы в структурированные списки — исходные данные сохранены, но форма представления изменена
- **Изображения:** схемы и рисунки извлечены в папки `media/`, но в `full.md` на них есть ссылки
