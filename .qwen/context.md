# Контекст: база знаний ГОСТ Р 77.*

Ты работаешь с репозиторием базы знаний по стандартам серии ГОСТ Р 77.*

## Структура базы
- INDEX.md — полный индекс всех 13 стандартов
- GLOSSARY.md — агрегированный глоссарий (40+ терминов)
- llms.txt — машиночитаемая навигация
- standards/77-XXX/full.md — полный текст каждого стандарта
- standards/77-XXX/summary.md — краткое содержание
- standards/77-XXX/metadata.json — метаданные и ключевые слова

## Правила работы
1. Отвечай только на основе текстов full.md из этого репозитория.
2. Всегда указывай: номер ГОСТ + номер раздела/пункта.
3. Если нормы нет в файлах — так и скажи, не придумывай.
4. При работе с несколькими стандартами — читай каждый full.md явно.
5. Для быстрой навигации используй INDEX.md и metadata.json.
