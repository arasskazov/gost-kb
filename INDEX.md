# Индекс стандартов ГОСТ серии 77

## О документе

Этот файл содержит полный перечень всех стандартов серии 77, представленных в данной базе знаний.

База знаний содержит нормативные документы в области поддержки жизненного цикла изделия (СПЖЦ).

## Структура индекса

Стандарты организованы по функциональным группам:

- **77.001–77.002** — Основные положения и термины
- **77.101–77.102** — Общие требования к поддержке ЖЦ
- **77.301–77.306** — Информационная модель изделия
- **77.402–77.404** — Программные средства и интероперабельность
